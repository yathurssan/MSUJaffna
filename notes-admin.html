Save changes

Saving downloads a new notes-data.js file. Nothing changes on the website until you upload that file to GitHub.

Now upload it to GitHub:
  1. Open your website's repository on GitHub.
  2. Click Add file, then Upload files, and drop in the notes-data.js you just downloaded.
  3. Click Commit changes. The website updates in about a minute.
